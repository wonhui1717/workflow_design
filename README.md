# 노코드 자동화 워크플로우 설계

## 프로젝트 개요

본 프로젝트는 반복적으로 수행되는 업무를 노코드 자동화 도구를 활용하여 자동화하고,
Trigger, Action, Filter 및 Router/Path의 개념을 실제 워크플로우에 적용하는 것을 목적으로 한다.

Project 1에서는 동일한 자동화 워크플로우를 **Make**와 **Zapier**에서 각각 구현하여
두 자동화 도구의 사용 방식과 특징을 비교하였다.

---

# Project 1. 평가 결과 자동 분류 및 이메일 통보 시스템

## 1. 프로젝트 목적

Google Sheets에 평가 결과가 입력되면 점수를 기준으로 결과를 자동 분류하고,
분류 결과를 별도의 Google Sheets에 기록한 후 Gmail을 통해 결과 안내 메일을
자동 발송하는 워크플로우를 구현하였다.

동일한 워크플로우를 **Make**와 **Zapier**에서 각각 구현하여
두 자동화 도구의 워크플로우 구성 방식과 사용성을 비교하였다.

---

## 2. 사용 도구

- Google Sheets
- Gmail
- Make
- Zapier

---

## 3. 입력 데이터 구조

Google Sheets의 `입력데이터` 시트는 다음과 같이 구성하였다.

| 이름 | 이메일 | 점수 | 등록시간 |
|---|---|---:|---|
| Test User | example@email.com | 85 | 테스트 시간 |

자동화 실행 결과는 다음 두 개의 시트로 분리하여 저장하였다.

- `통과자`
- `재검토자`

결과 시트의 구조는 다음과 같다.

| 이름 | 이메일 | 점수 | 결과 | 처리시간 |
|---|---|---:|---|---|

---

## 4. 워크플로우 설계

전체 자동화 흐름은 다음과 같다.

```text
Google Sheets에 새로운 행 추가
              ↓
         점수 조건 확인
              ↓
      ┌───────┴───────┐
      ↓               ↓
   점수 ≥ 80        점수 < 80
      ↓               ↓
   통과 처리        재검토 처리
      ↓               ↓
 통과자 시트       재검토자 시트
   행 추가            행 추가
      ↓               ↓
 통과 안내 메일     재검토 안내 메일
      └───────┬───────┘
              ↓
             완료
